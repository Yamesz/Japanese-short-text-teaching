# 日語教學網站工作流程

建立或維護以「さくら先生」為教學角色、面向繁體中文學習者的日語教學網站。

## 先選擇內容模式

- **一般級數短文**：新增 N5、N4、N3 等單篇閱讀教材時，沿用同級數相鄰單元的頁面、資料與共用模組。
- **階梯故事**：同一故事提供不同級數版本，或以章節推進難度時，沿用 Progressive 既有切換方式；只有設計選擇會改變故事結構時才詢問使用者。
- **影片或逐字稿系列**：來源素材切成多篇、每篇有時間碼或字幕範圍時，使用 japanese-source-series-generator。
- **網站共用功能**：首頁篩選、學習進度、TTS、卡拉 OK、測驗或共用樣式，先檢查現有模組，再集中修改共用實作。

專案的實際目錄、共用模組與相對路徑見 [site-architecture.md](references/site-architecture.md)。新增一般單元時可使用 resources/template-lesson.html 作為起始版型，並依最近的同類頁面調整。

## 一般短文必備教學單元

每篇 N5、N4、N3 一般短文都必須依以下順序呈現四個教學單元，不可省略或調換：

1. **精選單字**：整理理解本文所需的核心詞彙，附讀音與繁中釋義。
2. **動詞教室**：講解本文的重要動詞與用法，採個別動詞卡呈現，參考 `N5/文章1/index.html` 的「動詞寶庫」：
   - 每個重點動詞各用一張卡；動詞類別是卡片資訊，不可只把動詞分成第一、第二、第三類三大組，也不可漏掉中文釋義。
   - 卡片標示讀音、ます形與辭書形（適用時保留漢字），並標明第一／第二／第三類及繁體中文意思。
   - 每張卡提供活用表，至少列出辭書形、ます形、過去式、て形、ない形；可沿用網站既有的展開表互動。
   - 每張卡至少附一個自然且切合本文的日文例句和繁體中文翻譯；頁面支援 TTS 時，沿用既有朗讀按鈕。
   - 精選值得學習的本文動詞即可，不必收錄每個出現的動詞，也不固定卡片或例句數量。沿用共用互動時，確認展開按鈕和表格 ID 唯一且互相對應。
3. **助詞教室**：解析本文出現且值得學習的助詞，說明其在原句中的功能。
4. **さくら先生的精選文法教室**：整理本文的核心句型，提供清楚說明與自然例句。

每個單元至少要有一項直接連結本文的教學內容，不留空區塊或占位文字。詞彙與動詞區分工：精選單字以非動詞詞彙或慣用表現為主；動詞的主要解說集中在動詞教室，避免重複展開。其他單元（例如形容詞補充、文化小知識、隨堂測驗）依文章內容選擇加入，並放在上述四個必備單元之後。

## 教材品質原則

- 教學說明使用台灣繁體中文。日文原文、假名、例句與中文翻譯須互相對應。
- 依目標級數選擇詞彙與文法；不確定級數時標示為適讀程度，不宣稱官方分級結果。
- 逐句解析沿用該內容模式現有的 Ruby、羅馬字、翻譯和發音呈現方式；不要為了湊欄位而新增無教學價值的內容。
- 必備教學單元的內容以本文重點為準；例句應自然且能說明用法，不固定詞條、例句或測驗題數。
- 必備教學單元之外的詞彙補充、助詞延伸、形容詞、文化說明與測驗只在有教學價值時加入。
- 測驗答案要能由教材內容或教學說明支持，干擾選項應合理，回饋要清楚且友善。
- 使用圖片或其他來源素材時保留原始檔案與來源資訊。除非使用者明確要求，不要刪除或覆寫原始素材。

## 實作原則

1. 先檢查目標資料夾、同類單元與首頁入口，確認該模式目前使用的頁面和資料格式。
2. 優先沿用 js/ 下的共用音訊、朗讀、測驗、進度、UI 與 lesson-renderer 模組；避免複製播放器、測驗或進度邏輯。
3. 使用與目標頁面深度相符的相對路徑。一般 N 級單元位於 N5/文章N 等資料夾，回到主頁通常是 ../../index.html，樣式包含 ../../style.css 與本地 lesson.css。
4. 新增或更名單元時同步更新入口卡片、篩選標籤與唯一進度 ID。系列首頁與系列內單元要分別確認入口。
5. 保留既有單元的相容性；除非使用者要求，不要為了套用新模式而批次重寫舊頁。
6. 使用者要求結構驗收時，執行 scripts/check-site.ps1 並處理報錯；未要求驗收時，檢查本次修改涉及的連結、ID、模組與相鄰頁面即可。

Skill 規範的是內容與整合結果，不強制指定每個動畫、色碼或像素尺寸。視覺細節以共用樣式和目標系列的既有設計為準。
